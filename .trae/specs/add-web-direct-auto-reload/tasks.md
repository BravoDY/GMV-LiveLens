- [x] Task 3: 在调度器中实现自动刷新候选筛选与串行调度

  - [x] 实现候选筛选逻辑，只纳入满足网页直连、有效 `page_id`、已满 3 小时且不在保护状态中的任务。
  - [x] 实现全局串行与 10 分钟错峰控制，一次只选择 1 个任务执行自动刷新。

- [x] Task 4: 实现自动刷新执行、观察期与失败冷却收口

  - [x] 失败后设置 2 小时冷却，避免短时间反复刷新同一页面。
  - [x] 明确登录页、待登录、页面失效、窗口操作中等失败或跳过路径。

- [x] Task 5: 接入人工介入保护与统一日志
